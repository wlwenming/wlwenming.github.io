隐私政策

本网站（「文明的视界」）非常尊重您的隐私。本政策说明我们在您访问时可能涉及的信息处理方式。

我们收集什么

  • 本站为纯静态网站，不设置账户、不要求登录，也不主动收集您的姓名、邮箱、电话等个人身份信息。
  • 本站不使用 Cookie 来追踪您的行为，也不植入第三方分析脚本（如 Google Analytics）。

GitHub Pages 的日志

本站托管于 GitHub Pages。GitHub 可能作为底层服务提供方，自动记录访问日志（如 IP 地址、访问时间、请求路径等），这些日志由 GitHub 按其自有隐私政策处理，与本站无关。详情可参阅 GitHub 隐私政策。

本地存储

本站首页的「随机欢迎语」每次刷新都会重新随机，不依赖本地存储来保存任何数据。不执行 JavaScript 时，页面会显示一段写在 HTML 里的固定欢迎语。

外部链接

本站包含指向 GitHub 的链接。我们不对这些第三方网站的隐私实践负责，建议您阅读它们的隐私政策。

儿童隐私

本站内容适合所有年龄段访问，不刻意收集任何儿童的个人信息。

政策更新

本政策可能不时更新，更新后将在本页面公布，不另行单独通知。
